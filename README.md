# VARNIKA — Threads Between Worlds

Issue 01 / 2026. A responsive digital fashion editorial exploring contemporary international fashion through traditional craft roots.

## Run

Open `index.html` in a modern browser. No build or dependencies are required. For a local preview, run `python3 -m http.server 8000` from this folder.

## Experience

Eleven editorial sections, issue navigation, reading progress, scroll-drawn textile threads, a five-gesture horizontal cloth study and a keyboard-accessible three-look styling switch. Reduced-motion preferences are respected.

Palette: Scarlet Smile #942E3A, Cloud Dancer #F0EFEC, Hunter Green #3F5D3E, Lime Cream #DBE7C1, Ink #171816.

## Assets and provenance

Sixteen distinct AI-generated conceptual fashion/craft images. The three-look styling triptych intentionally studies the same textile. See IMAGE-USAGE.md and image-prompts.json. Images are not documentary photographs of specific makers or collections. Display typography uses installed Didot/Bodoni with a Times New Roman fallback; fonts are not redistributed.

## Validation

Reviewed on phone, tablet and desktop. Text and page overflow checks passed across 320–1920px, including breakpoint boundaries. Image loading, index, textile detail, horizontal controls and keyboard styling tabs were checked.

The companion Behance presentation is supplied separately as upload-ready images and project copy.
